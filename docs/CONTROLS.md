# Controls

The Steam Frame controllers, right-handed. The VR menu's LAYOUT tab shows the same page when SteamVR reports the Frame controllers.

## Starting

The first time, the launcher opens: press **Select Game...**, pick your disc image, then **Play**. After that the game starts straight into VR. In the headset, stand in the centre of your play space, face forward and click the right stick to set your height.

## On foot

| Control | Action |
|---|---|
| Left stick | Move |
| Right stick | Look. Push up to jump |
| Right trigger | Shoot. Hold to charge the beam |
| Left trigger | Lock on, scan |
| Right grip | Missile |
| Left grip | Map |
| B, held, then swing the cannon | Beam select (up Power, right Wave, down Ice, left Plasma) |
| A | Select |
| Left D-pad down | Morph Ball |
| Left D-pad up | Start / pause |
| Right stick click | Set height |
| Left stick click, or View | VR menu |
| Right shoulder | Auto Fire on/off (see below) |

X, Y, Menu, the left shoulder and the D-pad left and right have no action.

## Visors

Hold the left controller near your head and use its stick: up Combat, right X-Ray, down Thermal, left Scan. The stick does nothing else while the controller is at your head.

## Morph Ball

| Control | Action |
|---|---|
| Left stick | Roll |
| A | Bomb |
| Left D-pad down | Unmorph |
| B | Boost |
| Right grip | Power Bomb |
| Right trigger | Spider Ball |
| Left trigger | Ball camera |

## Auto Fire

The right shoulder switches Auto Fire on and off in first-person play, and a message, "Auto Fire On" or "Auto Fire Off", shows. To free the shoulder, set **AUTO FIRE BUTTON** on the VR menu's CONTROL tab to OFF.

- With Auto Fire on, a held right trigger fires the beam again and again at the beam's own rate. It does not charge.
- A hold keeps the mode it started with, so switching mid-hold changes nothing until you release.
- It starts off at every launch.
- The shoulder does nothing while the VR menu or the beam wheel is open.

## VR menu

Click the left stick, or press View, to open it. The CONTROL tab holds the control options, CALIBRATION the cannon, and CONFIG the launcher link. **OPEN LAUNCHER** there asks twice, then closes the game and opens the launcher.

## Left-handed and custom layouts

The launcher's Controller tab has **Right hand** and **Left hand**, and **Customize controller layout**. A custom layout assigns each action to any Frame control. The LAYOUT tab in the VR menu then lists what you assigned.
